How to automate with the event scheduler

The event scheduler does things at set times so you don't have to be there: make a fresh playlist every morning, put Friday night's show on air at 19:00, start the second stream for a sports match, or run any station command.

Add an event

Open Tools → Event scheduler or press F3. It opens in its own window, so you can keep it on a second screen.

  1. Press ➕ Add event and give it a name.
  2. Set the time it runs at (hour and minute) and tick the days.
  3. Optionally limit it to dates, for example a holiday schedule that runs from 24 to 26 December. An event outside its dates shows ○ not today.
  4. Choose what to Do (the actions are below) and fill in what it needs, such as a template, a playlist tab or a rule.
  5. Press ▶ Run now to try it straight away.

Each event has its own on/off tick, so you can park one without deleting it.

Recipes

  • A new playlist every morning: 05:55, every day, Generate a new playlist from a template → Breakfast.
  • A weekly show: build the show in its own playlist tab, then Friday 19:00, Put a playlist tab on air → Friday Night. End the show's tab with an Event row that puts Main back on air.
  • A sponsored news intro: 07:59, weekdays, Play adverts / jingles from a rule → News sponsor.
  • A second stream for a match: Saturday 14:45, Run a station command → ENCODER START 2, and 17:15, ENCODER STOP 2.
  • Quieter overnight: 00:00, Set volume 0.8; 06:00, Set volume 1.

Something every hour? An event runs at one time of day. For a station ID or a top-of-the-hour jingle every hour, make a jingle rule that plays every 1 hour on the clock in the advertisement scheduler, or an insert in your generator template.

Events in the playlist

Playlist → Add event puts an Event row in the running order. When playback reaches it, it runs a scheduler action, for example ending a show's playlist with "Put a playlist tab on air → Main" so Main carries on where it left off instead of dead air.
