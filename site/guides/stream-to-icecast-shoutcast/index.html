How to stream to Icecast or Shoutcast

RadioMaster has its own encoder, so it can send your station straight to an Icecast or Shoutcast server with no extra software. You can run several streams at once, for example a high and a low quality one, and RadioMaster reconnects by itself if the connection drops.

What you need

From your stream host or your own server, note the host (address), port, mount point (Icecast, for example /live), and the source password. Some hosts also give a username; on Icecast it's usually source. If you don't have a server yet, the start a station guide compares the options.

Add an encoder

  1. Open Tools → Streams / encoders.
  2. Press ➕ Add encoder and give it a name, for example Main 128k.
  3. Choose the Server type: Icecast, or Shoutcast (v2 DJ).
  4. Fill in Host, Port, Mount, Username and Password.
  5. Pick the Format and Bitrate (kbps).
  6. Fill in the station details listeners and directories see: Stream name, Genre, Description and Website. Tick List publicly if you want directories to list you.
  7. Leave Send track titles on so players show the song, and tick Connect on startup to go on air as soon as RadioMaster opens.
  8. Press ▶ Connect. The encoder shows when it's connected, and ⏹ Disconnect stops it.

Add more encoders the same way. Each one runs on its own, so a problem with one stream doesn't touch the others.

Permission: starting, stopping and changing encoders needs the Streaming permission. See users and permissions.

Formats and bitrates

FormatNeedsGood for
MP3Built inPlays everywhere. 128 kbps is the usual choice, 192–320 for music-first stations.
AACffmpegBetter sound than MP3 at the same bitrate. 64–96 kbps sounds good on mobile.
OpusffmpegThe best quality at low bitrates (48–96 kbps). Icecast only.
Ogg VorbisffmpegOpen format for Icecast. Some servers show titles only for MP3 and AAC.
FLACffmpegLossless, for studio links. Uses a lot of bandwidth.
CustomYour encoderAny program that reads PCM and writes a stream.

Shoutcast only takes MP3 or AAC, and RadioMaster warns you if you pick something else.

Getting ffmpeg

AAC, Opus, Vorbis and FLAC are made by ffmpeg. RadioMaster looks for it next to itself, in its settings folder and on the PATH. If it isn't found, the Streams window says so: press get ffmpeg to download it, then Choose… to point at the program, or Look again after installing it.

A custom encoder

Choose Custom to use any encoder. RadioMaster starts your Command, feeds it 16-bit 44.1 kHz stereo PCM on its input, and sends whatever it writes to its output to the server with the Content type you give. {bitrate} in the command is replaced with the bitrate. For example:

ffmpeg -f s16le -ar 44100 -ac 2 -i - -c:a libfdk_aac -profile:a aac_he -b:a {bitrate}k -f adts -

Streaming to AzuraCast

AzuraCast takes a live stream on its DJ port. In AzuraCast, add a Streamer/DJ account for the station (or do it from RadioMaster's AzuraCast tool). Then add an encoder with:

  • Server type Icecast, the AzuraCast server as the host and the station's DJ port (usually 8005) as the port.
  • Mount /, and the streamer's username and password.

The AzuraCast tool's Streamers/DJs page can fill encoder 1 with a DJ's login for you. When you connect, AzuraCast switches from AutoDJ to your live stream.

Sound cards and FM transmitters

Streams and sound cards run at the same time. In Settings → Audio devices → Outputs, tick every device that should play the on-air mix, each with its own volume: the studio speakers, headphones, or a sound card feeding an FM transmitter. Mark studio speakers as Studio monitor and they go quiet while the mic is on, while the stream and the other outputs keep playing.

Troubleshooting

  • It won't connect: check the host, port and mount, and that the password is the source password, not the admin one. The station log (bottom of the main window) says what the server answered.
  • It keeps dropping: RadioMaster reconnects by itself and waits a little longer between each try. If it never stays up, another source may already be connected to that mount.
  • No song titles: make sure Send track titles is on. With Ogg formats some servers only show titles for MP3 and AAC.
  • Sound is choppy for listeners: lower the bitrate, or check the upload speed of the computer that streams.
