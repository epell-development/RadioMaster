How to manage an AzuraCast station

RadioMaster's AzuraCast tool puts your AzuraCast station inside the studio. With just the address you see what's playing and who's listening; add an API key and you can skip songs, restart services, manage the AutoDJ queue, answer requests, upload media and look after your DJs without opening a browser.

1. Connect to your AzuraCast server

  1. Open Tools → AzuraCast station manager. The first time, it opens on the 🔑 Connection page.
  2. Type the Base URL of your AzuraCast server, for example https://radio.example.com.
  3. Press Find stations on this server and press Use next to your station. (Or type its Station short name or ID yourself.)
  4. Leave Enable polling on and choose how often to refresh with Poll every (s).

That's enough for the 📻 Overview page to show what's playing, the listen link and the number of listeners.

2. Add an API key to manage the station

To change anything on the station, RadioMaster needs an API key:

  1. In AzuraCast, open your account (top right) → API Keys → Add API key.
  2. Copy the key (it looks like id:secret) and paste it into API key on the 🔑 Connection page.
  3. Press Test API key.

The key can do whatever the AzuraCast account that made it can do, so use an account with rights to that station. Optionally set an Upload folder for files you upload from RadioMaster.

Permission: the AzuraCast tool can be allowed or blocked per user. See users and permissions.

Songs added to your playlist from AzuraCast are downloaded and cached, so they play like any local file.

Go live on AzuraCast

To broadcast from RadioMaster through AzuraCast instead of using AutoDJ, connect an encoder to the station's DJ port:

  1. On 🎤 Streamers/DJs, add a DJ account (or pick an existing one) and use the button to fill encoder 1 with its login.
  2. In Tools → Streams / encoders, check the encoder: server type Icecast, the station's DJ port (usually 8005), mount /, and type the DJ's password.
  3. Press ▶ Connect. AzuraCast puts your stream on air and AutoDJ steps aside until you disconnect.

More detail on encoders is in the streaming guide.

Troubleshooting

  • "This page needs an AzuraCast API key": add a key on the Connection page; only the Overview works without one.
  • The API key test fails: check the key was copied whole (both parts, with the colon), and that its account can manage this station.
  • No stations found: check the Base URL opens AzuraCast in a browser, including https://.
  • The encoder won't connect: the DJ account must be active (and inside its scheduled times if that's ticked), and the DJ port must be open on the server's firewall.
