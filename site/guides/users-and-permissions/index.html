How to set up users and permissions

Give every presenter their own login and decide what each one may do, from playing and editing playlists to streaming, settings and each individual tool. A presenter who can't change the adverts simply won't see that tool switched on.

The first account

The first time RadioMaster starts it asks you to Create administrator. That account can do everything, including managing other users. Passwords are at least 12 characters, and only a hash of each one is stored.

Add a user

  1. Signed in as an administrator, choose File → Users….
  2. Under Add a user, type a username and a password (12 or more characters).
  3. Tick Administrator only for people who should manage users and everything else.
  4. Choose the permissions and tools (below), then press Create user.

New presenter accounts start with sensible settings: they can play, fire jingles and edit playlists, but can't stream, change settings, or open the generator, advert and event schedulers, Audio FX, AzuraCast, plugins or library cleanup until you allow them.

Manage users

  • Change a user's role, permissions or tools at any time in File → Users….
  • Tick Disabled to stop someone signing in without deleting them. You can't disable your own account, and there must always be at least one active administrator.
  • Type a New password and press Set to reset a forgotten password.
  • The delete button asks Delete! / Keep first.

On RadioMaster Server, presenters sign in with the server's own username and password. See server security.
