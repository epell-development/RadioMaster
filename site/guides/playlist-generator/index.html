How to use the playlist generator

The playlist generator builds hours of programming from your music library in one click. You tell it what pools of songs you have (categories) and how an hour should sound (a template), and it fills the playlist, keeps artists apart and drops in jingles and hour markers for you.

Before you start

The generator picks songs from the Library, so add your music folders there first (the Library tab, then Rescan library from the File menu after you add new files). Open the generator with Tools → Playlist generator or Ctrl+G. It has three parts, top to bottom: Auto-playlist, Categories and Templates.

Can't open it? The playlist generator is a tool an administrator can allow or block per user. See users and permissions.

1. Make your categories

A category is a pool of tracks the generator can pick from. Each one has a name and up to three filters; leave a filter empty to mean "any".

FilterWhat it matches
folderTracks whose file is inside this folder (or any folder in it). Use … to pick it.
genreTracks whose genre tag contains this text, ignoring capitals. rock matches Rock, Soft Rock and Rock & Roll.
lengthShortest and longest track in seconds. A maximum of 0 means no limit. Handy for keeping long album versions or short IDs out.

A typical music station might have:

CategoryFilters
Currentfolder D:\Music\Current
Recurrentfolder D:\Music\Recurrent
Goldfolder D:\Music\Gold, length 120–420 s
Station IDsfolder D:\Jingles\IDs, length 0–30 s

Press ➕ Add category for each one. The delete button asks Delete! / Keep first, so a stray click won't lose anything.

2. Write a template

A template describes how the programming should sound. Press ➕ New under Templates, then set:

  • Name: what you'll pick it by, for example Daytime or Overnight.
  • Length: how much to make, from 5 minutes to 24 hours (1440 minutes).
  • Artist separation: how many tracks must pass before the same artist can play again. 8 to 12 suits most music stations.

The pattern

The pattern is the running order the generator repeats until the length is reached. Each step is a count and a source: a category, or the files of one of your advert or jingle rules. Press ➕ Add pattern step for each step. For example:

StepCountFrom
1.2 ×Current
2.1 ×Gold
3.1 ×Recurrent
4.1 ×Station IDs

That gives Current, Current, Gold, Recurrent, ID, then round again.

Inserts by time

Below the pattern you can add things that go in by time instead of by position, such as "every 15 min insert 1 × Station IDs". Press ➕ Add insert, then set the minutes, the count and the source. ➕ Add jingles is a shortcut that adds your first jingle rule every 15 minutes.

Times are counted along the generated running order using each track's length, so an insert every 30 minutes lands roughly every half hour of airtime wherever the playlist starts.

Hour markers

Tick Hour marker at the top of every hour and the generator places an hour marker where each new hour starts, so the station stays on the clock even if the songs run long or short.

3. Generate

  • ▶ Generate (replace playlist) clears the playlist and fills it with the template.
  • Append to playlist adds the new tracks after the last row, keeping what's already there.

The log shows how many tracks were made. If it says the generator produced nothing, check that the library has been scanned and that your category filters match some tracks.

Keep the playlist filled automatically

At the top of the window, tick Keep the playlist filled automatically, pick a template and how many minutes should always be left (for example "when under 30 min left"). RadioMaster checks every couple of seconds and appends a fresh batch from that template whenever the playlist runs low, so the station never runs dry.

Generate on a schedule

To make a new playlist at set times, use the event scheduler actions Generate a new playlist from a template or Add tracks from a template after the playlist. The same thing works as a station command in a playlist command row or from a plugin:

GENERATE Overnight
APPEND Daytime

Tips

  • Within one generated playlist, every track in a category plays once before any of them repeats, so big categories stay fresh.
  • If artist separation can't be met (a small category with few artists), the generator still picks a track rather than leaving a gap.
  • Timed inserts (jingles, IDs, adverts) don't count towards artist separation.
  • Make a template per daypart (Breakfast, Daytime, Evening, Overnight) and switch between them with the event scheduler.
  • While connected to RadioMaster Server, the library and folders are the server's, so a category folder is typed the way the server sees it, for example /srv/music/current.
