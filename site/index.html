What's on the desk

Everything a live studio needs

Broadcast automation for internet radio, community, student, hospital and FM stations: built for stations that run around the clock and for presenters who jump in live.

Playlists

As many as you need

Playlist tabs side by side. The one marked ▶ is on air; play any row of another tab and it goes to air. Every row shows its projected start time.

Timing

Hour markers

Wait for the top of the hour, finish the song and jump, or cut in exactly on time. The clock counts down to the next marker.

Transitions

Smart fading

Each track is analysed: silence is trimmed, cold endings get a tight mix, fade-outs overlap. Fine-tune any song in the waveform track editor.

Work zones

Fill every screen

One, two or three panels in the main window, plus as many Additional windows as you like for a second or third monitor.

Streaming

Icecast and Shoutcast

Several encoders at once with automatic reconnect and track titles, plus multiple sound-card outputs for FM and monitors.

On air

Built for live shows

Cart wall for jingles, microphone with music ducking, recorded voice tracks, a notepad for scripts, and a log of everything that played.

Adverts

Every N songs

"Every 5 songs, play 2 adverts" — random, taking turns, or all of them, from a folder or a hand-picked list. Jingles too.

Team

Users and permissions

Give every presenter their own login and decide who can play, edit playlists, stream, use AzuraCast or change settings.

Plugins

Make it yours

Run your own scripts when a song starts or the hour changes — post to Discord, update a website, light the ON AIR sign — and send commands back.

Running order

More than songs in a list

The Playlist menu adds rows that do things. Put them anywhere in the running order and RadioMaster handles them when they come up.

WaitEarly? Hold silence until the marker time.
SoftLate? Let the current song finish, then skip ahead to the marker.
HardCut in exactly on time with a quick crossfade, for news and network joins.
LineJust shows where each new hour starts — RadioMaster keeps these in the right place for you.

AzuraCast

Manage the station without leaving the studio

Point RadioMaster at your AzuraCast server to see what's playing and who's listening. Add an API key and run the station from the same window.

  • ServicesStart, stop or restart AutoDJ and the broadcast server, skip songs, disconnect a live DJ
  • QueueSee what AutoDJ plays next and remove songs
  • RequestsListener requests, cleared or added to your local playlist in one click
  • MediaBrowse folders, upload files, add songs straight to your playlist or queue them on AutoDJ
  • StreamersAdd and edit DJ accounts, then fill an encoder with their login
  • ReportsLive listeners, song history and the station schedule

Optional. Without a server RadioMaster streams to any Icecast or Shoutcast host.

Questions

Radio automation, answered

What is RadioMaster?

RadioMaster is free, open-source radio automation software for Windows, macOS and Linux. It plays your station from one screen: playlist tabs with live start times, hour markers, smart crossfades, adverts and jingles, a cart wall, voice tracks, text to speech, Icecast and Shoutcast streaming and AzuraCast station management. It suits internet radio, community, student, hospital and FM stations.

Is RadioMaster really free?

Yes. RadioMaster is open source under the MIT licence. There is no account, subscription, trial or paid edition: every feature is in the free download, and the source code is on GitHub.

Does RadioMaster run on Mac and Linux?

Yes. The same app with the same features runs on Windows 10 and 11, macOS 12 or newer, and 64-bit Linux (PulseAudio, PipeWire or ALSA). Each release has a Windows installer and portable zip, a macOS app and a Linux tar.gz.

Can RadioMaster run a station 24/7 without a presenter?

Yes. Build playlists with the playlist generator, keep them on the clock with hour markers, schedule adverts and jingles by song count, minutes or set times, and use the event scheduler to put playlists on air, generate new ones or run station commands at set times.

Can I stream to Icecast, Shoutcast or AzuraCast?

Yes. RadioMaster has a built-in encoder for Icecast 2 and Shoutcast 2, including AzuraCast DJ ports, in MP3, AAC, Opus, Ogg Vorbis or FLAC. Several streams can run at once with automatic reconnect and track titles. Sound-card outputs for an FM transmitter work at the same time.

Is RadioMaster an alternative to RadioBOSS, SAM Broadcaster or ZaraRadio?

RadioMaster covers the core of a broadcast automation desk (playlists, hour markers, crossfades, advert scheduling, carts, voice tracking, streaming and reports) for free, on Windows, macOS and Linux. It is an independent project and is not affiliated with any of those products.

Where do I get help?

Ask on the RadioMaster Support Discord or open an issue on GitHub. Every release and what changed is on the Updates page, and installed copies update themselves in one click.
