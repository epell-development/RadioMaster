RadioMaster vs RadioBOSS: a free, open-source RadioBOSS alternative

RadioBOSS from DJSoft.net is a long-established, paid radio automation program for Windows. RadioMaster follows a similar studio layout and covers the core of the job for free, on Windows, macOS and Linux. Here is a fair look at how they differ.

Where RadioMaster fits

  • Free and open source. MIT licence, no account, trial, subscription or paid edition. The source code is on GitHub.
  • Windows, macOS and Linux. The same app and features on all three, plus RadioMaster Server for headless Linux and Windows Server.
  • Built-in encoder. Stream to Icecast 2, Shoutcast 2 and AzuraCast DJ ports in MP3, or AAC, Opus, Ogg Vorbis and FLAC through ffmpeg. See stream to Icecast or Shoutcast.
  • AzuraCast in the studio. Manage the AutoDJ queue, requests, media, playlists and DJs from inside RadioMaster. See manage an AzuraCast station.
  • Remote presenting. Connect to a RadioMaster Server from anywhere, or run the station from a phone with the web portal. See broadcast from anywhere.

What RadioMaster can't do yet matters too:

  • It is young. RadioMaster is at version 0.2; long-established products have had many more years of testing in real stations.
  • Downloads aren't code-signed yet, so Windows SmartScreen and macOS Gatekeeper warn the first time (why).
  • No ASIO driver support yet on Windows; it uses the standard Windows audio devices.
  • Support is community-based, through Discord and GitHub issues, not a paid support contract.

Where RadioBOSS fits

  • Maturity. RadioBOSS has been developed for many years and is used by a lot of stations, with a deep set of options in every area.
  • Older Windows versions. It supports Windows 7 and 8.1, and both 32-bit and 64-bit systems. RadioMaster needs 64-bit Windows 10 or 11.
  • Vendor support. A paid licence includes 12 months of support from the developer.
  • Extras such as DTMF-triggered events and a built-in streaming server, which RadioMaster doesn't have.

If you rely on one of those, RadioBOSS may still be the better fit. If you want a free, open tool that also runs on a Mac or Linux, try RadioMaster alongside it: both can run on the same computer.

Switching to RadioMaster

  1. Download RadioMaster and install it next to your current software. Nothing needs to be removed first.
  2. Add your music folders to the library. RadioMaster reads the tags already in your files.
  3. Open your existing playlists: RadioMaster opens M3U and M3U8 playlists, which most automation software can export.
  4. Re-create your clocks in the playlist generator, your advert rules in the advertisement scheduler and your timed events in the event scheduler.
  5. Add your stream in Tools → Streams / encoders with the same server details, test it on a spare mount, then switch over.

Questions

Is RadioMaster a free alternative to RadioBOSS?

Yes. RadioMaster is free, open-source radio automation software with playlists, hour markers, crossfades, a playlist generator, advert and event scheduling, voice tracking and Icecast/Shoutcast streaming, like the core of RadioBOSS. It is a separate, independent project.

Does RadioMaster run on Mac and Linux, unlike RadioBOSS?

Yes. RadioMaster has native apps for Windows 10 and 11, macOS 12 or newer and 64-bit Linux, and RadioMaster Server runs headless on Linux or Windows Server. RadioBOSS is a Windows program.

Can I move my RadioBOSS playlists to RadioMaster?

Export them as M3U playlists and open them in RadioMaster. Clocks, advert rules and scheduled events are set up again in RadioMaster's own playlist generator, advertisement scheduler and event scheduler.
